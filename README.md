# ИИ-администратор парикмахерской: запуск 24/7

## 0. Что где лежит

| Файл | Зачем |
|---|---|
| `apps_script/Code_additions.gs` | Новые действия Apps Script + блокировка от двойной записи |
| `app/reminders.py` | Фоновая задача: напоминание за 1 час, проверка каждые 5 минут |
| `app/confirmations.py` | Ответы клиента «Да» / «Отменяю» |
| `app/booking_service.py` | Запись/отмена с проверкой конфликта («Слот уже занят клиентом …!») |
| `app/integrations.py` | Запросы в Apps Script и отправка в WhatsApp (Green-API) |
| `app/main_integration_example.py` | Как подключить всё в ваш `main.py` (lifespan, `/health`, `/webhook`) |
| `Dockerfile`, `requirements.txt`, `.env.example` | Деплой |

Приложение должно называться `app.main:app` (файл `app/main.py`). Если у вас иначе — поправьте последнюю строку `Dockerfile`.

## 1. Подготовка таблицы и Apps Script

1. В листе «Записи» должны быть колонки: `ID | Дата | Время | Мастер | Имя | Телефон | Услуга | Статус | Напоминание | Создано`.
2. Колонки **Дата, Время, Телефон** → Формат → Числа → **Обычный текст**.
3. Вставьте код из `Code_additions.gs` в проект Apps Script (старые `book_slot` и `cancel_slot` замените).
4. **Развернуть → Управление развертываниями → ✏️ → Версия: «Новая версия» → Развернуть.**
   Без этого шага Web App продолжит работать на старом коде.
5. Скопируйте URL веб-приложения (он не меняется при новых версиях) — это `GAS_URL`.

## 2. Проверка локально

```bash
cp .env.example .env        # заполните значения
pip install -r requirements.txt
set -a; source .env; set +a
uvicorn app.main:app --port 8000 --workers 1
```

Проверка напоминания: добавьте в таблицу запись на «сейчас + 60 минут» со статусом «Записан» и своим номером, подождите до 5 минут — придёт сообщение, в колонке «Напоминание» появится «да».

## 3. Деплой на Render

1. Залейте проект на GitHub (файл `.env` НЕ коммитить).
2. Render → **New → Web Service** → выберите репозиторий.
3. **Language/Runtime: Docker** (Render найдёт `Dockerfile` сам).
4. **Instance Type: Starter (платный).** Бесплатный тариф не подходит — см. примечание ниже.
5. **Health Check Path:** `/health`.
6. **Environment** → добавьте все переменные из `.env.example` (`GAS_URL`, `GREEN_ID_INSTANCE`, `GREEN_API_TOKEN`, `ADMIN_PHONE`, `OPENAI_API_KEY`, `TZ=Asia/Almaty` и т.д.).
7. **Create Web Service**, дождитесь статуса Live. Проверьте `https://<имя>.onrender.com/health` → `{"status":"ok"}`.

## 4. Деплой на Railway

1. Railway → **New Project → Deploy from GitHub repo**. Railway сам найдёт `Dockerfile`.
2. Вкладка **Variables** → добавьте переменные из `.env.example`.
3. **Settings → Networking → Generate Domain** (получите публичный адрес).
4. Проверьте `https://<домен>/health`.
5. Следите, чтобы сервис был на платном плане/кредитах и не засыпал. Актуальные условия смотрите на сайте Railway.

## 5. Webhook Green-API

В личном кабинете Green-API → ваш инстанс → настройки:
- URL вебхука: `https://<ваш-домен>/webhook`
- Включить уведомления о входящих сообщениях (`incomingMessageReceived`).

## 6. Важные замечания

- **Один воркер.** Планировщик живёт внутри приложения; несколько воркеров = несколько планировщиков. Дубли сообщений всё равно исключены (атомарная отметка `set_reminded`), но лишней нагрузки лучше избежать.
- **Бесплатный Render засыпает** после 15 минут без входящих запросов, а вместе с ним замирают и напоминания. Для работы 24/7 нужен платный инстанс. Пинг снаружи — ненадёжный костыль.
- **Часовой пояс.** Серверы работают в UTC. Время сравнивается в `Asia/Almaty` (переменная `TZ`, и константа `TZ` в Apps Script). Проверьте, что в настройках проекта Apps Script стоит тот же пояс.
- **Окно напоминания 55–65 минут.** «Ровно за час» при проверке раз в 5 минут технически невозможно, поэтому напоминание уходит за 55–65 минут до записи. Записи, созданные менее чем за 55 минут до визита, напоминание не получают.
- **Отмена** не удаляет строку, а ставит статус «Отменено». Слот при этом свободен для новой записи.
- **Логи** смотрите в панели хостинга (Render → Logs, Railway → Deployments → Logs): там видно каждое отправленное напоминание.
